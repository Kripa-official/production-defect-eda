A data analysis project focused on manufacturing defect patterns, repair costs, inspection methods, and severity breakdowns.

## Project Overview

This notebook analyzes a manufacturing defects dataset to uncover:
- Distribution of defect types
- Repair cost trends
- Inspection method patterns
- Severity-wise breakdowns
- Product-level defect relationships

## Dataset

The analysis uses a manufacturing dataset with columns such as:
- Defect ID
- Product ID
- Defect Type
- Defect Date
- Defect Location
- Severity
- Inspection Method
- Repair Cost

## Key Insights

- Structural, Functional, and Cosmetic defects are compared across the dataset.
- Repair cost is analyzed using summary statistics and visualizations.
- Defect distribution is explored with charts.
- Product ID and severity relationships are plotted for pattern discovery.
